# 课间校园地图

线上地址：https://cd-png.github.io/campus-compass/

新版支持学校地图预览、底图自动切换、手动添加/编辑/删除课程、导入预览、逐行校验、重复行合并、课程冲突提示和 JSON 课表备份。运行 `npm run check` 验证。

上海师范大学奉贤校区内置官方平面图，可放大滚动查看，原始来源为奉贤校区管理委员会 2025-04-04 发布的《奉贤校区平面图》：https://lwh.shnu.edu.cn/a4/95/c17257a435349/page.htm 。本地图片保留官方图内容，仅压缩尺寸；平面图没有地理配准，不用于 GPS 定位或实际步行路线。实时位置、坐标绑定请切换地理地图。徐汇校区和其他学校使用在线地理地图预览；搜索结果、校区中心与教室坐标应分别核对。

地理地图使用 Esri 卫星图与 OpenStreetMap 标准底图，联网加载并保留来源标注；底图不可用时显示错误并支持切换重试。

运行 `npm start`，访问 http://localhost:3000 。无需安装依赖。

点击校名设置学校。支持 OpenStreetMap 地点搜索与地图、手动 WGS84 坐标、按学校保存教室位置、浏览器实时定位、课程导航和本地课表。

导入文本格式每行一节：`周五,14:00,15:35,数据结构,第二教学楼,A302,陈老师`。图片 OCR 提取文字后需要人工整理，复杂网格课表尚不能自动重建。未实现单双周、节次、学期日期和后台推送。

在线地图、搜索、OCR 需要网络；定位需要 localhost 或 HTTPS 与用户授权。应用无法读取设备地图软件内部数据。真实教室位置通过用户在地图上绑定获取，未绑定时不会生成虚假坐标。地图服务可能在部分网络中不可达。中国大陆设备定位和其他地图供应商可能使用不同坐标系，本页真实地图与手动绑定统一使用 WGS84。

课程、学校、收藏与教室坐标保存在浏览器 localStorage。网站没有用户账户或服务端存储。打开地图搜索会向对应服务发送关键词；地点检索与底图请求发送给 OpenStreetMap 相关服务。
