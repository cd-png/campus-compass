# 课间 · 校园课表与地图

运行 `npm start`，打开 http://localhost:3000 。Node 18+，不需要安装依赖。运行 `npm run check` 执行本地检查。

## 1.4 课表工作台

文件/文本识别支持 Excel、CSV/TSV、JSON、HTML表格、ICS、PDF文字层及图片OCR。复杂合并单元格、截图排版或扫描PDF需要在预览中核对；扫描PDF请先截图。Excel、PDF、OCR组件首次使用需要联网下载。关键词与相邻上下文识别在浏览器完成，不会自动上传文件。

导入后可逐格补全课程、星期、起止时间、教学楼、教室、教师和备注，再追加或替换当前课表。问答填写按课程名、星期、时间、地点、教师逐步提问。每周课表可拖拽调整星期和时间，保留原时长、按30分钟吸附，也可点选改时、点击编辑精确时间、撤销上次移动。冲突需要核对。

只有节次的课程必须先确认学校作息；不猜测具体上课时间。周次、学期、单双周保留在备注，目前每周展示，不根据这些规则过滤。

## AI连接

「导入我的课表 → 模型设置」填写支持 Chat Completions 的服务地址、模型名和 Key；支持视觉输入的模型才可直接读图。应用不附带模型、Key或额度，目前没有已验证可用的模型。调用前需单独同意发送本次课表内容，模型输出先进入编辑预览。

本地Node版通过后台调用；Key仅进程内存，重启丢失。也可设置环境变量 `AI_BASE_URL`、`AI_MODEL`、`AI_API_KEY` 后运行。Ollama地址支持 `http://127.0.0.1:11434/v1`，需先自行安装并启动所选模型。

GitHub Pages采用浏览器直连，Key仅当前标签页内存，服务需允许CORS。不要把AI Key放入公开仓库；面向所有用户的产品应使用有身份校验、限流和密钥管理的后台。

## 五校官网导入

已预置上海师范大学、南京邮电大学、陕西师范大学、郑州大学、长安大学官方首页。授权后打开官网，由用户自行进入教务系统登录、导出或复制个人课表，再上传/粘贴识别。不收集学校密码、验证码或Cookie；尚未适配各校登录后私有接口。

本地Node可在单次授权后读取五校官方域名的公开HTML课表；拒绝内网网址、检查重定向。不携带学校登录态。GitHub Pages没有后台，不能绕过学校跨域和登录限制。

## 高德地图与校园通行约束

所有活动地图、学校预览、地点搜索与步行服务统一接入高德JS API 2.0；不再启用OSM、卫星图或其他地图提供商作回退。没有Key时显示明确配置入口，青禾大学示意图仍仅作演示。

「高德地图设置」支持Web端（JS API）Key及securityJsCode，或安全代理serviceHost。已创建域名限制为cd-png.github.io的网页Key，并在公网标签页验证道路地图加载。尚未完成真实步行路线联调。

Cloudflare安全代理源码：amap-proxy-worker.mjs，部署配置：wrangler.jsonc。AMAP_KEY和AMAP_SECURITY_CODE已写入Cloudflare加密Secret；安全密钥未写入源码或GitHub。代理仅转发限定的地点检索、步行和样式接口，验证网站来源与Key，不记录请求或密钥。测试：`node amap-proxy-worker.test.mjs`。Worker已部署至https://campus-amap-proxy.3815790653.workers.dev；当前网络访问该地址连接超时，尚未通过真实代理检索验证。前端已准备公开Key和代理地址的默认配置，待网络连通验证成功后再同步公网，不能将部署成功等同于访客可用。Workers免费额度和网络可达性以实际账号及部署验证为准。

官方配置文档：https://lbs.amap.com/api/javascript-api-v2/guide/abc/jscode

设备与历史教学楼坐标保持WGS84；显示、地点检索与高德步行路线做GCJ-02转换。定位仍需浏览器/系统授权；不读取地图App内部数据。起终点仅在用户开启定位后发送给高德服务。

「校园通行范围」支持在高德地图上绘制并核对校园边界、标记禁行区域。未设置或未确认校园范围时直接使用高德步行路线、距离与预计时间，并提醒可能经过校外道路；可参照高德底图校区轮廓手动核对范围，不把底图轮廓冒充已验证围墙。确认范围后，起终点在校园外、路线中任一线段越界或经过禁行区域时拦截，距离与时间留空。多条返回路线仅选择通过检查者；不将校外绕行或直线当作可行路线。

尚未取得可验证的上海师范大学精确校园边界与完整通行数据，未内置猜测的矩形边界。通过数据校验仅表示「校内候选路线」，不保证围墙、封路、开放时间或路网遗漏符合现场情况，不能冒充已确认可通行。

原固定网址：https://cd-png.github.io/campus-compass/ 。本地修改需另行发布到仓库后才会更新公网版本。
